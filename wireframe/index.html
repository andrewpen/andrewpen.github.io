Page 2 · Atomic inventory

The primitives

17 recurring patterns
4 codified · 13 inline

The elements the compositions on page 3 are assembled from. Specimens here are drawn at true values — real radii, padding, type and accent colours — not in the greyscale used for the page-1 layout wireframe.

None of these exist as components. Four are CSS classes in theme.css (.a3-badge, .lift/.lift-t, .apb-ticker, .apb-rail). The other thirteen are inline style objects retyped at each use site — the counts below are occurrences across the 14 .tsx files, not imports.

Tokens

The only values with a single source of truth.

PINK#BE3372
MINT#4FE7AF
CYAN#11C4D4
DEEP#0C4E8C
NAVY#141f29

boldPalette.ts also exports ink(rule): CYAN and MINT are too bright for small text on light grounds, so it swaps them for BLUE and DEEP while the brighter value still paints the rule or bar.

--ap-font-sansInter → system fallback
--ap-font-monoJetBrains Mono → ui-monospace

Declared in theme.css. The mono face carries every eyebrow, meta line, stat label and metric — 45 uses. It is the redesign's loudest signal, and the only typographic decision applied consistently.

07 · Dead ends and gaps

Places where the architecture promises something the site does not yet deliver.

  • 1
    Five of six essays have no page. Only the-compound-professional-is-not-coming has hasFullPost: true and a built entry. The other five render as non-clickable cards marked "Full essay coming soon" on both the homepage and /writing.html.
  • 2
    Case studies are outside the design system. Three standalone HTML files, no React, no shared Navbar or Footer — reached from Work, but they leave the redesign's visual language entirely.
  • 3
    Subscribe has no backend. Present on three of four pages. Submitting opens a pre-filled mailto:; nothing is stored and no list exists.
  • 4
    Each essay needs a hand-written HTML entry. Posts live in content.ts, but publishing one also requires a new file under writing/ and a new line in vite.config.ts's rollup inputs. Miss the second and the page builds but never ships.
  • 5
    Nav link arrays are duplicated four times. Each page component declares its own navLinks and footerLinks. Adding a destination means editing four files, and they have already drifted — the footer carries "Writing" on some pages and "Portfolio" on others.
